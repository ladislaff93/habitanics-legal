### Description (summary)

Habitanics transforms habit-building into a gardening simulation. Each habit you
create becomes a crop in a personal garden, and the crop's visual growth reflects
your consistency.

Core features:
- Each habit displays as a real crop (tomatoes, carrots, wheat, onions)
- Daily streak tracking with visual consequences for missed days (wilting, not resets)
- Coin economy: harvest grown crops for currency, buy new seeds
- Difficulty scaling (trivial → hard) with matching rewards
- XP and levelling system unlocking additional garden tiles
- Real-time crop health based on completion consistency
- Market system with seasonal seeds
- Reminders and to-dos alongside habits

### Target audience (from listing)

Former habit-app users seeking engagement, cozy-game enthusiasts (Stardew Valley
energy), students, remote workers, gamers, and people frustrated with punishing
gamification (streak resets, avatar damage).

## Keyword research

Goal: rank for queries with **download intent** that a small new site can
realistically win — long-tail, problem-led queries rather than head terms.

### Content map

- **Homepage `/`** — brand + "gamified habit tracker" head term. Hero, how it
  works, screenshots, guides, FAQ (each answer links to a guide), CTA.
- **`/guides/`** — one page per keyword above. Structure of every guide:
  1. Answer the searcher's actual question first (SEO: query in H1 + first paragraph).
  2. Practical, honest advice that stands alone.
  3. Integration: how to do it in Habitanics, step by step.
  4. CTA to the App Store + internal links to tools/blog/other guides.
- **`/blog/`** — comparison/editorial content (Habitica alternatives, etc.).
- **`/tools/`** — free interactive tools that earn links and capture
  top-of-funnel queries, each with a CTA to the app.
